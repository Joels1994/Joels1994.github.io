Location: Audio Signal Processing Lab, IIT Gandhinagar, in collaboration with Space Application Center, Ahmedabad.

Development of a technique that estimates the geolocation of a ground-based emitter using the signal received by a planar array on board a Low Earth Orbit (LEO) satellite. Considering the need to reduce the size, weight, and power (SWaP) of the payload, this project aims to provide accurate source localization with the minimum possible number of sensors.
